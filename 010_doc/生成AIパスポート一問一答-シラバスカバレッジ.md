# 生成AIパスポート一問一答-シラバスカバレッジ

## 目的

GUGA「生成AIパスポート試験」公式シラバスのキーワードと、本プロジェクトの問題IDを対応付ける。問題の追加・改訂時に、未対応の学習項目を確認するために利用する。

## 対象資料

- シラバス：[GUGA 生成AIパスポート試験シラバス](https://guga.or.jp/assets/syllabus.pdf)
- 適用版：2026年2月試験より適用
- 参照日：2026-09-29
- 問題データ：[src/questions.ts](../src/questions.ts)
- 登録問題数：200問（基礎120問＋中級〜応用80問）

## 判定基準

| 記号 | 意味 |
|---|---|
| ○ | 問題文、選択肢、解説または周辺知識でキーワードを直接扱っている |
| △ | 関連する概念は扱っているが、キーワード固有の説明・事例としては補強が必要 |
| — | 対応する問題がない |

本表の「○」はシラバス学習項目の確認を助けるための判定であり、試験範囲の完全な網羅や合格を保証するものではない。問題はすべて公式シラバスを参照したオリジナル問題であり、公式過去問ではない。

## 今後の更新手順

1. 公式シラバスの改訂版と参照日を確認する。
2. 問題データに新しい問題IDを追加する。
3. 本表の対応問題IDと判定を更新する。
4. 「—」と「△」の項目から追加問題を検討する。
5. `npm run validate:questions`、`npm run test`、`npm run build`を実行する。
